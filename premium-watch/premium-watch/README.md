# プレミア化候補ウォッチャー 導入手順（約30分）

サーバー契約は不要です。GitHub Actions（無料）で毎日自動実行します。

## あなたがやること
1. **ntfy** アプリ（Android）をインストールし、推測されにくいトピック名（例: `premium-watch-x7k29q`）を購読する
2. **GitHub** アカウントを作り、新しいリポジトリ（Private推奨）にこのフォルダの中身をアップロード
3. リポジトリの Settings → Secrets and variables → Actions → New secret
   名前 `NTFY_TOPIC`、値は手順1のトピック名
4. Actions タブ → lookup-jan → Run workflow を実行（1回で約250本ずつ。728本なので3回ほど、終わるまで繰り返す）。ソフト名から最安値.comのJANコードを自動で調べ、`watchlist.csv` に保存されます。確定できなかったものは `review.csv` に候補つきで出るので、私に貼ってください
5. 監視リストができたら、Actions タブ → daily-watch → Run workflow で試運転

## 動作確認の状況
- ページ解析は、実際のページ文字列（新品在庫なしの例）で検証済みです。
- 未確認: 在庫ありのページの形式、GitHubのサーバーからアクセスできるか（ボット検知の可能性あり）。
- 想定外のページが返ると、誤判定せず「取得失敗」として数え、3割超で異常通知が届きます。
- 利用規約・robots.txtの確認はご自身でお願いします。

## 注意
- 判定のしきい値は `monitor.py` 冒頭で変更できます。最初の1〜2週間は様子見期間です。
- GitHubのサーバーからのアクセスが相手サイトにブロックされる場合があります。その場合は月数百円のVPSに移す案に切り替えます。
- Web画面（docs/index.html）は、Privateリポジトリでは無料のGitHub Pagesで公開できません。画面が必要な場合は、私が別途ブラウザ用の画面を用意します。
